# minor_project_1
🧬 GroupDNA — WhatsApp Group Analytics

Your WhatsApp Group, Decoded.
Spotify Wrapped, but for your friend group.

GroupDNA is a Python-based data analytics minor project that analyzes a WhatsApp-style group chat and converts raw messages into meaningful group statistics.

The project uses NumPy and Pandas to identify member activity, chat patterns, active hours, top chatters, and overall group statistics.

🚀 Features
👥 Member Analysis
Total number of group members
Individual message count
Most Active Member
Least Active Member
Average messages per member
💬 Chat Analysis
Total messages
Top 5 chatters
Member activity ranking
Message distribution
⏰ Time Analysis
Most active chatting hour
Number of messages during the peak hour
Hourly group activity
📊 Group Statistics
Maximum messages by a member
Minimum messages by a member
Average messages per member
Total messages
